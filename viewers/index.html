About This System

The UCWS DV pipeline aggregates 17+ data sources into a unified demand signal for every English local authority. This map shows the latest processed run, enabling analysis of where exempt accommodation pressure is highest, which authorities are at fiscal risk, and how trends are evolving year-on-year.

296 Local Authorities

Full coverage of all English LA districts, unitary authorities, and metropolitan boroughs.

25+ Demand Signals

Temporary accommodation, rough sleeping, care leavers, MARAC, housing register, deprivation and more.

Automatic Updates

Map data is refreshed after each Workflow 1 pipeline run. Last-updated timestamp shown in the map header.

Open Data Backup

All exported data is versioned on GitHub — accessible without login at any time.

How to Use the Map

  • View demand: Polygon colour shows TA household count (light = low, dark red = high).
  • Click any LA: Side panel opens showing all 25+ signals for that authority.
  • Hover: LA boundary highlights. Tooltip shows name.
  • Zoom & pan: Mouse wheel or trackpad. Navigation controls top-left.
  • Legend: Bottom-left. Toggle with ▼ button on mobile.
  • Full-screen: Button in top-right corner of map.
  • Mobile: Tap to select an LA, pinch to zoom.
  • Data freshness: Run ID and update date shown in the header bar.

Technical Details

Data Sources (17+)

  • DLUHC H-CLIC — Statutory homelessness & temporary accommodation (quarterly)
  • DLUHC Rough Sleeping Snapshot — Annual count of people sleeping rough
  • DfE — Care leavers in semi-independent & supported accommodation
  • SafeLives MARAC — Multi-Agency Risk Assessment Conference case data
  • DWP STAT-Xplore — Housing Benefit asylum seeker caseload
  • DLUHC CORE — Social housing waiting list (housing register)
  • MHCLG RO4 — Local authority housing revenue account expenditure
  • MHCLG EFS — Exceptional Financial Support recipients
  • Published S.114 notices — LA fiscal distress flags
  • MHCLG IMD 2019 — Index of Multiple Deprivation
  • ONS MYE — Mid-year population estimates

Refresh Frequency

Data is updated automatically after each Workflow 1 pipeline run (currently approximately weekly). The run ID and timestamp are shown in the map header.

Boundaries

LA polygon boundaries from ONS Open Geography Portal — LAD Dec 2024, England only, simplified for web display (GeoJSON WGS84 RFC 7946).

Raw Data Access

  • la_boundaries.geojson — Full combined GeoJSON (~9.5 MB)
  • staging_la_signals_latest.json — Signals only (~172 KB)
  • latest.json — Metadata (run_id, timestamp)
