# S4 Node 1 — Fetch 17-21 Accommodation CSV 2020–2023

**Type:** HTTP Request

## Purpose

Fetches the DfE care leaver 17-21 accommodation by LA dataset for the 2023 release, covering reporting years 2019 to 2023 (year ending 31 March). The EES data catalogue assigns a new UUID per release; this UUID is fixed to the 2023 release and will not update in place.

## URL

```
https://explore-education-statistics.service.gov.uk/data-catalogue/data-set/888d6288-a4c8-4d00-86a9-ddb01c46b34d/csv
```

## Configuration

- Method: GET
- Response Format: Text
- Put Output in Field: `data`
- Authentication: None

## Output

1 item, `data` field containing CSV. Columns: `time_period`, `time_identifier`, `geographic_level`, `country_code`, `country_name`, `region_code`, `region_name`, `old_la_code`, `la_name`, `new_la_code`, `age`, `accommodation_type`, `number`, `percentage`.

## Notes

- `time_period` values: 2019, 2020, 2021, 2022, 2023
- `age` values: `17 to 18 years`, `19 to 21 years`. Both are summed into the single `17-21` age group in Node 4
- `new_la_code` may carry pre-2023 codes for new unitaries (Cumberland, Westmorland and Furness, North Yorkshire, Somerset), routed through `la_code_lookup` in the upsert query
- County councils appear on `E10` codes
- National and regional rows are filtered out in Node 4
- Suppression symbols `c`, `k`, `z`, `x` handled in Node 4
- **Retained only for reporting years 2019 and 2020.** From 2021 the current release supersedes this file with revised figures. See [s4_care_leaver_source.md](../s4_care_leaver_source.md)

## Connection

- Input: Manual Trigger, runs in parallel with Nodes 2 and 3
- Output: Merge node, input 1

## Verified Output

1 item, `data` populated, years 2019–2023 confirmed present. (2026-03-31)
