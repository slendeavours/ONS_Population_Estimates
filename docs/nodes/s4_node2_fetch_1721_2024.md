# S4 Node 2 — Fetch 17-21 Accommodation CSV 2024

**Type:** HTTP Request

## Purpose

Fetches the DfE care leaver 17-21 accommodation by LA dataset for the 2024 release (reporting year ending 31 March 2024). Separate UUID from the 2023 release.

## URL

```
https://explore-education-statistics.service.gov.uk/data-catalogue/data-set/a8264b74-10ad-4c7d-969a-97e150fcbb1d/csv
```

## Configuration

- Method: GET
- Response Format: Text
- Put Output in Field: `data`
- Authentication: None

## Output

1 item, `data` field containing CSV. Same schema as Node 1: `age`, `accommodation_type`, `number`.

## Notes

- Covers reporting years 2020 to 2024; overlaps Node 1 on 2020–2023
- From 2024 onwards `Semi-independent, transitional accommodation` means **Ofsted-registered supported accommodation only**. Before 2024 the label included unregistered provision. Do not trend across this boundary
- Hampshire flagged by DfE for 2024 data quality issues following a records system change. Retained, no special handling
- **Superseded for 2021 onwards** by the current release, which carries DfE revisions

## Correction, 2026-08-20

An earlier version of this note stated that the 2025 release dropped the LA-level accommodation breakdown entirely, making 2024 the most recent LA-level data available. That is not the case. Dataset `a504e4b8-79ef-4196-8e2a-977fdc039dc3` carries reporting years 2021 to 2025 at local authority level with the full accommodation breakdown, under renamed columns. See [s4_care_leaver_source.md](../s4_care_leaver_source.md).

## Connection

- Input: Manual Trigger, runs in parallel with Nodes 1 and 3
- Output: Merge node, input 2

## Verified Output

1 item, `data` populated, year 2024 confirmed. (2026-03-31)
